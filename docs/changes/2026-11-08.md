## 新增 Notepad3 打包环境（builders/notepad3 + workflow + 文档）

- `builders/notepad3/build.ps1`：新增构建脚本。版本发现走 GitHub Releases API（`/releases?per_page=30` 或指定版本时的 `/releases/tags/RELEASE_<ver>`），过滤 `draft` / `prerelease`，tag 必须匹配 `^RELEASE_(\d+\.\d+\.\d+\.\d+)$` 且资产名 `Notepad3_<ver>_x64_Portable.zip` 中的版本必须与 tag 一致；下载后按 Release 资产 `digest` 的 sha256 强制校验（缺失或不合法即 throw），解压到 `build/stage/notepad3`（zip 根即安装根）。
- 语言包裁剪：`lng\` 白名单 `@('en-GB','zh-CN')`，删除 23 个语言目录共 12,015,632 字节（约 11.46 MB），暂存树 20.99 MB → 9.53 MB；保留 `lng\mplng.dll`、`lng\np3lng.dll` 两个共享加载器。裁剪后断言两套语言的 `mplng.dll.mui` / `np3lng.dll.mui` 存在、无残留语言目录。
- 冒烟测试：布局哨兵（`Notepad3.exe`、`minipath.exe`、`Notepad3.ini`、`Docs\License.txt`、`grepWin\LICENSE.txt`、`Themes\*.ini`、中英语言文件）；静态 CRT 导入断言（解析 `Notepad3.exe` / `minipath.exe` 的 PE 导入表，禁止 `vcruntime140` / `vcruntime140_1` / `msvcp140` / `ucrtbase` / `api-ms-win-crt-*`）；PE `FileVersion` 归一化后必须等于解析出的版本。不启动 GUI（无 `/?`、`/v`、静默启停）。
- `builders/notepad3/setup.iss`：Inno Setup 6 安装器。默认目录 `C:\pf\Notepad3`（无版本后缀）、固定 `AppId`、管理员权限、`UninstallDisplayIcon`、`SetupIconFile`、随仓库自带的简体中文语言包。`Notepad3.ini` 走 `onlyifdoesntexist uninsneveruninstall`（保护用户配置）；`Themes\` 按"已存在则跳过"处理，`Favorites\` 为空目录由 `[Dirs]` 创建。PATH 写入系统 PATH（幂等追加/精确移除 + `WM_SETTINGCHANGE`）。文件关联做成 `[Tasks]`：`.txt .log .ini .md .json .xml .yml .yaml .csv` 默认勾选，`.bat .cmd` 与 `.ps1` 默认不勾；只写 `Applications\Notepad3.exe`、`SupportedTypes`、`.<ext>\OpenWithProgids`（REG_NONE）、`RegisteredApplications` 与 `Software\win-env\Notepad3\Capabilities`，不写 `UserChoice`、`.ext` 默认值、`txtfile`，也不碰 `notepad.exe`。安装后经 `[Run]` 以 `runasoriginaluser` 打开 `ms-settings:defaultapps?registeredAppMachine=Notepad3`，由用户手动设默认；`[Code]` 在勾选关联任务时调用 `SHChangeNotify(SHCNE_ASSOCCHANGED, ...)` 刷新"打开方式"。
