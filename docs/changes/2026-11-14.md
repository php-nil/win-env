# 2026-11-14

## Rust 安装包新增可选入口：安装 C/C++ 编译工具链（内嵌 VS Build Tools 在线引导器）

背景：包内已提供 CRT/SDK 头文件与库、以及 rust-lld，但**没有 C 编译器前端**。`rusqlite`（`bundled`）、`zstd-sys`、`openssl-sys` 这类 `-sys` crate 与在 `build.rs` 嵌 `.rc` 资源的项目（Tauri）都需要 `cl.exe` / `rc.exe`，机器上无 VS 时 `cargo build` 直接失败。微软 EULA 不允许单独再分发 `cl.exe`，因此方案是"内嵌官方在线引导器 + 安装完成后由用户勾选调起"，而不是自行打包编译器。

### 设计要点：与 Rust 安装结果完全解耦、且不静默

- 入口放在 **"完成"页的勾选项**（`[Run]` + `postinstall nowait skipifsilent shellexec unchecked`），不是安装中的可选任务：Rust 早已装完，工具链装不装、成功还是取消，都不影响本包安装结果。
- **不加 `--quiet`**：保留微软安装器自己的图形界面，用户能看到真实进度与成功/失败结果，也可随时取消。
- `nowait`：向导调起后立即退出，不阻塞、不接管其进度；引导器失败不会让本安装包报错。
- `skipifsilent`：`/SILENT` 静默安装时不显示也不执行，保持无人值守语义。
- 默认**不勾选**：避免"点完成即被拉走 2–3 GB"。
- 仅在探测不到可用 MSVC 工具链时显示（`Check: NeedsVcBuildTools`），已装 VS 的机器完全不受影响。

### 改动

- `builders/rust/build.ps1`：新增 `$VcBuildToolsUrl = https://aka.ms/vs/17/release/vs_BuildTools.exe`；编译安装包前下载引导器到 `build/cache/vs_BuildTools.exe`（aka.ms 指向当前 17.x，缓存旧文件一律删除，与 `vc_redist.x64.exe` 处理一致），读取其 `FileVersion` 并以 `/DVcBootstrapper=<path>` 传给 ISCC；`build-info.json` 增加 `vcBuildTools` 字段；`release-notes.md` 的组件表与"默认行为"同步。
- `builders/rust/setup.iss`：
  - 预处理守卫 `#if FileExists(VcBootstrapper)` → `#define HaveVcBuildTools`；未传该 define（手工跑 ISCC）时 `[Files]`/`[Run]` 条目整段消失，安装器仍可编译。
  - `[Files]`：引导器释放到 `{%TEMP}\win-env\vs_BuildTools.exe`（不用 `{tmp}`：`nowait` 启动后 Setup 会清理临时目录，文件必须活过清理）。
  - `[Run]`：`--norestart --nocache --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended --lang zh-CN en-US`，`postinstall nowait skipifsilent shellexec unchecked`，`Check: NeedsVcBuildTools`，`Description` 说明体积/耗时/不影响 Rust。
  - `[Code]`：新增 `NeedsVcBuildTools`（= `not SystemMsvcUsable`）；删除原 `VerifyVcInstall`（结果判定交还给用户可见的微软安装器，无需安装器后台复检）。
  - 按仓库约定，Pascal 侧只用字符串拼接，不用 `Format` / `BoolToStr` / `Ord`。
- `doc/rust.md`：§3 重写该条目（收尾页勾选、默认不勾选、可见 UI、`nowait`/`skipifsilent`、失败不影响本包、卸载不移除、兜底 LLD 段保留时的共存行为）；§4 组件来源表增加引导器行（说明为何不做离线 layout：2+ GB 超 GitHub Release 单资产上限）；§7 更新"含 C 依赖的 crate"条目。
- `AGENTS.md` §3.1：为"安装器不在安装期下载/拼装"补上这一唯一例外。
- 取舍：**不内嵌离线 layout**（约 2+ GB，超出单资产 2 GB 上限）；**不自行打包 cl.exe**（EULA 不允许再分发）；**不注册卸载项**（工具链归微软安装器管理，卸载本包不碰它）；**不在安装期静默执行**（长耗时且无法判断成败）。
