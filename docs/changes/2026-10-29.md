# 2026-10-29

## 修复：PHP 8.5 re-spin 包名导致 windows.php.net 版本发现落空

- **现象**：`build-php.yml` 在 `Resolving PHP 8.5 release` 阶段报 `Could not resolve latest PHP 8.5.x from windows.php.net` 并 exit 1，listing 页本身可访问。
- **根因**：官方把 8.5.12 的安全重建版命名为 `php-8.5.12-1-nts-Win32-vs17-x64.zip`（带 `-1` re-spin 后缀），原解析正则只认三段版本；`Test-VersionString` 与 `Sort-Object { [version]$_ }` 同样不接受 `-N` 后缀，Inno 的 `VersionInfoVersion` 又只收最多四段纯数字。
- **变更**：
  - `builders/php/build.ps1`：版本发现正则接受可选 `-N` 后缀；新增 `Get-VersionSortKey`（`8.5.12-1` → `8.5.12.1`）供排序；`Test-VersionString` 接受 re-spin；新增 `$PhpVersionInfo` 并以 `/DMyAppVersionInfo` 传给 ISCC。
  - `builders/php/setup.iss`：`VersionInfoVersion` 改用 `MyAppVersionInfo`（未传时回落到 `MyAppVersion`）。
  - `.github/workflows/build-php.yml`：`php_version` 输入说明补充 re-spin 示例（`8.5.12-1`）。
  - `doc/php-8.5.md`：同步 workflow 参数、组件来源与设计约定；`doc/lessons.md`：新增 §33。
- **验证**：本机 `builders/php/build.ps1 -SkipCompile` 与完整构建均通过；产物 `php-8.5.12-1-setup-x64.exe`，`FileVersion=8.5.12.1`、`ProductVersion=8.5.12-1`，冒烟测试（PHP/Xdebug/APCu/Composer/nilpack）全过。
